# 🧠 知识仓库

双视角个人知识管理系统——**学习流**按输入/输出组织，**知识网**按领域分类，两套逻辑互联互通。

## 🏗️ 两套分类体系

### 📥📤 学习流

| 视角 | 包含 | 含义 |
|------|------|------|
| **输入** | 书·影·文·播·英 | 你消费的一切信息 |
| **输出** | 项目·灵感·SOP·复盘 | 你创造的一切价值 |
| **工具** | 工具 | 你使用的武器 |

### 🌐 知识网

按知识领域自动归类（文学·历史·编程·设计·效率…），每个条目通过 `domain` 字段定位。同一个条目可以跨多个领域。

两套视角**共享同一份数据**，切换即看，互不干扰。

## 📦 数据模型

| 字段 | 说明 | 示例 |
|------|------|------|
| `type` | 类型（决定学习流位置） | book/movie/article/podcast/english/idea/project/review/sop/tool |
| `domain` | 知识域（决定知识网位置） | ['文学'] / ['编程·科技', '效率·成长'] |
| `title` | 标题 | |
| `creator` | 创作者 | |
| `status` | 状态 | |
| `rating` | 评分 1-5 | |
| `sub` | 分类 | |
| `extra` | 额外信息 | |
| `tags` | 标签 | |
| `excerpt` | 简介 | |
| `notes` | 笔记 | |
| `links` | 链接条目标题 | |
| `steps` | SOP步骤 [{text,done}] | |
| `prompts` | 复盘问题 [{q,a}] | |

## 🚀 启动

```bash
start reading-collection\index.html
```

## ⚡ 快捷键

- `Ctrl+K` 添加条目
- `Ctrl+S` 保存
- `Esc` 返回/关闭
